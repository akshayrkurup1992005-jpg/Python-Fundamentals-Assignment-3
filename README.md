# Python Fundamentals – Assignment 3

## 📌 About the Project

This repository contains my Python Fundamentals Assignment 3. It demonstrates the use of `while` loops, `for` loops, control statements, and functions through simple Python programs.

## 🎯 Objectives

- Understand and implement `while` and `for` loops.
- Practice control statements such as `break`, `continue`, and `else`.
- Learn to use Python's `range()` function.
- Create reusable functions for calculations.
- Improve logical thinking and problem-solving skills.

## 🛠️ Technologies Used

- **Language:** Python
- **Environment:** Jupyter Notebook
- **File Format:** `.ipynb`

## 📚 Programs Included

### 1. Number Guessing Game
A simple number guessing game that demonstrates a `while` loop and control statements.

### 2. Multiplication Table Generator
Generates a multiplication table using a `for` loop and Python's `range()` function.

### 3. BMI Calculator
Calculates Body Mass Index (BMI) using a user-defined Python function.

## ▶️ How to Run

1. Download or clone this repository.
2. Open `Assignment3.ipynb` in Jupyter Notebook.
3. Run the code cells in order.
4. Enter the required inputs to see the results.

Through this assignment, I gained practical experience with Python loops, control flow, functions, user input, and basic calculations.
